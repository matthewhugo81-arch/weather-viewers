Comparison note: every panel uses Wetterzentrale's Accumulated Precip. field. Values are cumulative from the model initialization time to the selected forecast lead (for example, T+24 shows the model-total precipitation accumulated from T+0 through T+24). Panels are aligned to the same valid time; a model is left unavailable when it has no native output frame at that exact hour rather than substituting a different valid time.
Map imagery is loaded directly from Wetterzentrale. Source attribution is retained on every map. Wetterzentrale states that its maps/data may be linked free of charge for non-commercial use with source attribution; commercial use requires permission.
