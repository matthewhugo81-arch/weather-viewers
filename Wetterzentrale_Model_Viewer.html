How this viewer works

Wetterzentrale's current chart PNG filenames encode the model, run cycle, forecast lead and variable. This version is deliberately animation-only so run-to-run changes remain spatially aligned. For models with the required forecast steps, this viewer keeps the valid time mathematically fixed by increasing the forecast lead as you step back through earlier run cycles. EC ENS is the exception: Wetterzentrale exposes its ensemble-mean charts at 24-hour forecast steps, so 00Z/12Z EC ENS history is compared at the same T+ lead.

Example

06Z T+114 → 18 h older run 12Z T+108 → 12 h older run 18Z T+102 → 6 h older run 00Z T+96 → newest/reference run Animation always progresses oldest → newest.

Important Wetterzentrale limitation

These direct chart URLs represent Wetterzentrale's current stored run slots, not an unlimited archive. The viewer treats ECMWF and EC ENS as 00/12 only because Wetterzentrale's 06/18 ECMWF PNG slots can contain stale old charts. Therefore GFS, GFS ENS and ICON can use 00/06/12/18 cycle slots, while GEM, ECMWF, EC ENS and UKMO EU are primarily 00/12 comparisons. EC ENS mean output is 24-hourly (T+0, 24, 48 … 240), so its 00Z/12Z history uses the same forecast lead instead of requesting unavailable 12-hour-offset leads. Other models continue to use exact same-valid-time matching where the required forecast hour exists.

All-model comparison

Switch Mode to All models • same valid time. Choose a reference 00Z/12Z cycle, T+ lead and a run age (reference, 12 h older, 24 h older, etc.). The viewer then cycles ECMWF, EC ENS, GFS, GFS ENS, UKMO EU, GEM and ICON maps from the same initialisation cycle and exactly the same valid time. Models that do not supply that lead/variable are skipped.
