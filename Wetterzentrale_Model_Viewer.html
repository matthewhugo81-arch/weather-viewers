How this viewer works

Charts are checked against the initialisation and valid dates printed on Wetterzentrale images. The availability check runs approximately every 30 minutes; uncertain dates and charts from a different run date are excluded. A green status means both the indexed dates and image loading passed. The displayed copies are fixed at the check time, so a source update cannot change their dates mid-comparison. Forecasts stop at T+240.

Runs and forecast hours

UKMO EU: 00/12Z through T+168; 06/18Z through T+66. ICON: 00/12Z through T+180; 06/18Z through T+120. ECMWF: 00/12Z every 6 hours through T+144, then daily through T+240; 06/18Z through T+144. GFS, GFS ENS and AIFS: 6-hour steps through T+240. GEM: 00/12Z, 6-hour steps through T+240. EC ENS: 00/12Z, daily steps through T+240.

Comparison dates

History uses the previous stored cycle slots with the same valid date, where an exact forecast step is supported. EC ENS history uses the same forecast lead and labels the resulting earlier valid date explicitly. All-model comparisons require the same initialisation date and valid date. Unavailable models are listed in the buttons below; panels show only loaded charts together. A model awaiting that dated run is marked unavailable, even if a previous day's image exists. Direct cycle filenames are rotating slots, so arbitrary 24/48-hour archive selections are not offered.

Availability and reload

If the date index is missing or over 75 minutes old, charts are withheld until a fresh check is available. Reload fetches the date index again and checks and displays the same verified chart copy. Publication can be partial while a run is updating. See latest availability check.
