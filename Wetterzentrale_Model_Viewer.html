How this viewer works

Charts load directly from Wetterzentrale, as in v9. Availability means the image loaded, not that its printed dates were automatically verified. Run dates are not inferred from a separate background snapshot, because it can lag behind these live images. Always compare the Init and Valid dates printed on the charts: a cycle slot can still contain yesterday's run while today's output is publishing. Forecasts stop at T+240.

Runs and forecast hours

UKMO EU: 00/12Z through T+168; 06/18Z through T+66. ICON: 00/12Z through T+180; 06/18Z through T+120. ECMWF: 00/12Z every 6 hours through T+144, then daily through T+240; 06/18Z through T+144. GFS, GFS ENS and AIFS: 6-hour steps through T+240. GEM: 00/12Z, 6-hour steps through T+240. EC ENS: 00/12Z, daily steps through T+240.

Comparison dates

History is anchored to the selected run: earlier cycles are ordered oldest left, with the selected run last and opened by default. For a selected 12Z run, the order is the preceding 18Z, then 00Z, 06Z and 12Z. Forecast-hour offsets target the same valid time; publication can temporarily leave an older printed date in a slot. EC ENS uses the same forecast lead, so its earlier cycle targets an earlier valid time. These are requested comparisons; the printed chart dates are authoritative. Unsupported cycles, variables and forecast hours are excluded. Loaded panels appear together without empty gaps.

Availability and reload

The viewer does not wait for a GitHub availability index or copied images. Charts are reused briefly while navigating; after three minutes, revisiting a selection requests current source images. Visible charts refresh automatically every five minutes, keeping existing images visible until replacements load. Returning to the tab refreshes overdue charts. Reload forces fresh requests immediately. Wetterzentrale may publish a run progressively. An unavailable image can be retried with Reload.

Precipitation

Rain loads only when selected. The Rain / Height-MSLP button keeps the same model, run and forecast hour. Amounts are in mm over the period printed at the top of each chart; that period varies by model and forecast range, so compare equal accumulation periods. The forecast hour is the end of that period. ECMWF rain is supplied through T+144; ensemble-mean rain is not offered here. T+0 has no forecast accumulation. Source Init/Valid dates remain authoritative.
